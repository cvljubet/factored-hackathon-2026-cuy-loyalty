# Cuy Loyalty

Project workspace for the Factored Hackathon 2026 Cuy Loyalty solution.

## Repository Layout

- `frontend/`: user interface
- `backend/`: application services and APIs
- `agents/`: agent workflows and tools
- `data/`: source data, transformations, schemas, and pipelines
- `ml/`: baseline, model artifacts, and evaluation
- `infrastructure/`: infrastructure and deployment configuration
- `tests/`: unit, integration, and evaluation tests
- `docs/`: architecture, contracts, evaluation, deployment, and limitations

See the README in each area for its intended contents.
